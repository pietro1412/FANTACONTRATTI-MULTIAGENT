Cosa cambia rispetto alle card attuali
  • Due colonne asimmetriche (pattern "pannello"): la colonna leghe è compatta e scansione verticale; la colonna destra dà il quadro di stagione senza rubare il focus.
  • Il pulsante diventa un dettaglio: il pallino rosso = "c'è da fare", il budget = valore; la riga intera è il target del click. Niente più CTA per card.
  • L'attività recente è contesto, non rumore: vive nella sidebar con un orizzonte temporale (24h) ed entra nella pagina solo se c'è movimento.
  • Budget complessivo in numerone Oswald con barra blu→oro: un colpo d'occhio sul portafoglio di stagione (stile Finanze).
  • Mobile: le colonne si impilano in ordine di importanza (leghe → attività → budget), nessun troncamento (Assioma 2).
